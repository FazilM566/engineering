## 4. Часть A: модели и обучение (C1-C4)

Опишите коротко и сопоставимо:

- C1 (simple-cnn-base):простая CNN без аугментаций
- C2 (simple-cnn-aug):простая CNN, но с аугментациями
- C3 (resnet18-head-only): обучается только классификационная голова.
- C4 (resnet18-finetune): частичное fine-tune (layer4 + fc).

Дополнительно:

- Loss:CrossEntropyLoss
- Optimizer: Adam
- Batch size: 128 для С1,С2; 64 для С3,С4
- Epochs (макс): 15 для С1,С2; 10 для С3,С4
- Критерий выбора лучшей модели: метрика accuracy

## 5. Часть B: постановка задачи и режимы оценки (V1-V2)

### Если выбран detection track

- Модель: FasterRCNN_ResNet50_FPN
- V1: `score_threshold = 0.3`
- V2: `score_threshold = 0.7`
- Как считался IoU: частное между площадью пересечения двух рамок и общей площадью.
- Как считались precision / recall: precision = TP / (TP + FP),recall = TP / (TP + FN);TP (True Positives) = IoU ≥ 0.5 И класс совпал,
FP (False Positives) = IoU < 0.5 ИЛИ класс не совпал,FN (False Negatives) = объекты в датасете, которые модель не нашла

## 7. Анализ

- простая CNN ведёт себя не лучшим образом, тк в датасета большое колличесво изображений и много классов, модель слишком проста для такой высокой сложности.
- аугментации дали устойчивое улучшение ввиде отсутсвия переобучения, на графике это очень хорошо видно;
- pretrained ResNet18 помогла справится с высокой сложности, тк обчуна на большом массиве данных;
- head-only отличается от partial fine-tuning показателем точности за счет размораживания на втором этапе ключевых слоев;
- Precision/Recall/F1 — стандарт для детекции, показывают balance между точностью и полнотой,а IoU — оценивает качество совпадения рамок, поэтому эти метрики второй части подходят под задачу.
- при переходе от V1 к V2 модель стала строже отбирать свои предсказания.
- наиболее показательной ошибкой модели оказались ложные срабатывания (False Positives) — модель упорно "видела" объекты там, где их нет.
