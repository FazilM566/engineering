# HW14 – эмбеддинги, FAISS, оценка retrieval и mini-RAG по базе знаний

## 1. Кратко: что сделано

- База знаний состоит из набора данных из Dataset: BBCSport.База знаний состоит из новостных статей о футболе, каждая из которых содержит факты, события, команды, игроков и результаты матчей. - Что изменилось после обновления базы знаний: модель в своих предскзааниях опиралась на новые источники, которые не использовала ранее при одних и тех же вопросах.
